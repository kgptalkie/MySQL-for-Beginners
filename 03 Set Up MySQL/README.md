# Section 3: Set Up MySQL

Start here once MySQL Server and your SQL tool are installed (lessons 3.3 to 3.7).

- `S3-12-try-it-tasks.sqlnb`: try the practice first; `S3-12-try-it-solution.sql` has the answers.
